# Estudo Python

Repositorio criado para organizar aulas e exercicios de introducao a Python.

O projeto contem exemplos praticos usados durante o aprendizado da linguagem, separados entre arquivos de aula e desafios/exercicios.

## Estrutura

```text
estudo-python/
|-- Aulas/
|   |-- Fase06.py
|   |-- Fase07.py
|   |-- Fase08.py
|   `-- Fase09.py
`-- Exercicios/
    |-- ex001.py
    |-- ex002.py
    |-- ...
    `-- ex027.py
```

## Conteudos estudados

- Saida de dados com `print()`
- Entrada de dados com `input()`
- Tipos primitivos: `int`, `float`, `bool` e `str`
- Conversao de tipos com casting
- Operadores aritmeticos
- Ordem de precedencia
- Formatacao de strings com f-strings
- Metodos de verificacao de strings, como `isnumeric()`, `isalpha()` e `isalnum()`
- Uso de modulos e bibliotecas com `import` e `from ... import`
- Modulo `math`: arredondamento, truncamento, potencia, raiz quadrada e fatorial
- Modulo `random`: numeros aleatorios, escolha e sorteio de listas
- Manipulacao de strings: fatiamento, analise, transformacao, divisao e juncao
- Conversoes de medidas, moedas e temperaturas
- Calculos de porcentagem, media, area, aluguel e tabuada
- Operacoes com nomes, frases e digitos de numeros
- Reproducao de audio MP3 com `playsound3`

## Como executar

Para executar qualquer arquivo, use o Python pelo terminal:

```bash
python Aulas/Fase09.py
```

Ou, para executar um exercicio:

```bash
python Exercicios/ex027.py
```

Alguns exercicios usam bibliotecas externas. Para o exercicio de audio, instale a dependencia antes de executar:

```bash
pip install playsound3
```

## Exercicios

- `ex001.py`: mostra a mensagem "Ola, Mundo!" na tela.
- `ex002.py`: le o nome do usuario e exibe uma mensagem de boas-vindas.
- `ex003.py`: le dois numeros e mostra a soma entre eles.
- `ex004.py`: le um valor digitado e mostra informacoes sobre o tipo e caracteristicas do texto.
- `ex005.py`: mostra o antecessor e o sucessor de um numero inteiro.
- `ex006.py`: calcula dobro, triplo e raiz quadrada de um numero.
- `ex007.py`: calcula a media de duas notas.
- `ex008.py`: converte metros para centimetros e milimetros.
- `ex009.py`: mostra a tabuada de um numero.
- `ex010.py`: converte dinheiro em reais para dolares.
- `ex011.py`: calcula area de parede e quantidade de tinta necessaria.
- `ex012.py`: aplica 5% de desconto no preco de um produto.
- `ex013.py`: aplica 15% de aumento no salario.
- `ex014.py`: converte temperatura em Celsius para Fahrenheit e Kelvin.
- `ex015.py`: calcula o valor de aluguel de um carro por dias e quilometragem.
- `ex016.py`: mostra a parte inteira de um numero real.
- `ex017.py`: calcula a hipotenusa de um triangulo retangulo.
- `ex018.py`: calcula seno, cosseno e tangente de um angulo.
- `ex019.py`: sorteia um aluno de uma lista.
- `ex020.py`: sorteia a ordem de apresentacao de alunos.
- `ex021.py`: reproduz um arquivo MP3.
- `ex022.py`: analisa um nome completo com maiusculas, minusculas e contagem de letras.
- `ex023.py`: separa unidade, dezena, centena e milhar de um numero.
- `ex024.py`: verifica se o nome de uma cidade comeca com "SANTO".
- `ex025.py`: verifica se um nome contem "SILVA".
- `ex026.py`: conta ocorrencias da letra "A" e mostra suas posicoes na frase.
- `ex027.py`: mostra o primeiro e o ultimo nome de uma pessoa.
