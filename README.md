# Estudo Python

Repositorio criado para organizar aulas e exercicios de introducao a Python.

O projeto contem exemplos praticos usados durante o aprendizado da linguagem, separados entre arquivos de aula e desafios/exercicios.

## Estrutura

```text
estudo-python/
├── Aulas/
│   ├── Fase06.py
│   └── Fase07.py
└── Exercicios/
    ├── ex001.py
    ├── ex002.py
    ├── ex003.py
    └── ex004.py
```

## Conteudos estudados

- Saida de dados com `print()`
- Entrada de dados com `input()`
- Tipos primitivos: `int`, `float`, `bool` e `str`
- Conversao de tipos com casting
- Operadores aritmeticos
- Ordem de precedencia
- Metodos de verificacao de strings, como `isnumeric()`, `isalpha()` e `isalnum()`

## Como executar

Para executar qualquer arquivo, use o Python pelo terminal:

```bash
python Aulas/Fase07.py
```

Ou, para executar um exercicio:

```bash
python Exercicios/ex004.py
```

## Exercicios

- `ex001.py`: mostra a mensagem "Ola, Mundo!" na tela.
- `ex002.py`: le o nome do usuario e exibe uma mensagem de boas-vindas.
- `ex003.py`: le dois numeros e mostra a soma entre eles.
- `ex004.py`: le um valor digitado e mostra informacoes sobre o tipo e caracteristicas do texto.

## Objetivo

Este repositorio serve como registro da evolucao nos estudos de Python, reunindo conceitos basicos e pequenos desafios praticos.
